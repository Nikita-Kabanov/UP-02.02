# Модуль парсинга документации и формирования оглавления

**Задание:** Разработка программного модуля, который считывает текстовый файл (Markdown) и автоматически создает из него структурированное оглавление.

## Команда (2 человека)
* Участник 1 — Тимлид / Backend (работа с Git, логика парсинга)
* Участник 2 — Frontend / Тестировщик (вывод, тесты)

## Структура проекта
* `src/` — исходный код программы
* `tests/` — тесты
* `docs/` — документация
